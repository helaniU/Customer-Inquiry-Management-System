# Coffee Ninja - Customer Inquiry Management System

A full-stack web application for recording, filtering, and managing customer support inquiries through their operational lifecycle.

## Tech Stack
* **Frontend:** Next.js (App Router), React, Tailwind CSS, Axios
* **Backend:** Node.js, Express.js, Prisma ORM, JWT, Zod Validation
* **Database:** PostgreSQL (Neon Serverless)

---

## Local Setup & Quick Start

### Prerequisites
* Node.js v18+
* PostgreSQL database or Neon DB connection string
